# Credits & Attribution

Built for the **Steal//Remake Hackathon** (Neura AI Club).

## 1. Primary Inspiration & Format Remix

- **Original Project:** [Duolingo](https://www.duolingo.com)
  - Used as inspiration for the gamified language-learning interaction format: progressive unit path, bite-sized lessons, interactive answer-checking with instant feedback sheets, streak counter, and rank progression.
  - **Zero code, assets, trademarks, or character branding** from Duolingo were used. All SVG artwork, corporate content, color schemes, audio, and game logic are original creations.
